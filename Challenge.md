**Challenge: Mastering Git Basics in a Real-World Project**

**Scenario:**

You have joined a development team working on a Java project. Your task is to **set up version control using Git**, manage your code efficiently, and track changes properly.

**Part 1: Setting Up a Git Repository**

- **Use case:** Initialize and configure a Git repository.
- **Tasks:**
    - Create a new Java project folder.
    - Initialize a Git repository inside the project.
    - Configure your user name and email for Git.
    - Create a .gitignore file to exclude unnecessary files (e.g., *.class, .idea/, target/).

**Part 2: Basic Git Commands for Version Control**

- **Use case:** Track changes and commit updates.
- **Tasks:**
    - Create a new Java file (Main.java) and add a simple program.
    - Use Git commands to check the status of your repository.
    - Add the new file to the staging area and commit it with a meaningful message.
    - Modify the Java file and commit the changes again.

**Part 3: Viewing and Managing Commit History**

- **Use case:** Track and review past changes in the project.
- **Tasks:**
    - View the commit history using Git commands.
    - Use a command to see the differences between the last two commits.
    - Undo the last commit without losing changes.
    - Restore a file to a previous version from commit history.

**Part 4: Working with Remote Repositories (Bonus Challenge)**

- **Use case:** Collaborate using GitHub, GitLab, or Bitbucket.
- **Tasks:**
    - Create a remote repository on GitHub.
    - Link your local repository to the remote repository.
    - Push your local commits to the remote repository.
    - Clone a repository and create a new branch for feature development.
